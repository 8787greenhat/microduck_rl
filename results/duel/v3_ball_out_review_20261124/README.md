# v3 seed 1 球出界分析與獨立診斷影片

正式評測仍是167/600進球，402/600以球出界結束。本包沒有修改原評測、模型、PPO或獎勵，也沒有重新訓練。
來源與原始600局見相鄰 `../v3_seed1_20261124/`。這次新增的是既有資料分析及一次獨立推論的錄影。

## 原600局可以確定的事情

402個出界局裡，最後觀測觸球為對手260局（64.7%）、我方141局（35.1%）、同時觸球1局。
328局曾啟動我方踢球技能，74局未啟動；不是402局都因為沒有觸發出腳。

| 出界局的最後觀測觸球 | 曾啟動我方踢球技能 | 未啟動我方踢球技能 |
|---|---:|---:|
| 我方 | 89 | 52 |
| 對手 | 238 | 22 |
| 同時 | 1 | 0 |

最後觸球方不等於出界原因；技能啟動是整局共現，不代表最後一碰發生於技能內。
例如238局「我方曾出腳、最後對手觸球」可能含擋球、碰撞或後續推球，目前不能直接全部標成被擋射門。
原CSV沒有球最後位置／出界邊／完整接觸時間序列，所以無法據此替402局逐一確定射偏、推球、門框反彈或對手碰出。

**統計注意：**原始 `flag_ball_out` 有576局為真，其中包含167個我方進球和7個失球。
進球越過邊線也會亮此旗標；正式優先判進球。分析必須用互斥的 `end_reason == ball_out`，才能得到402，不能把576都當失敗。
各方向出界為196／300與206／300。

## 獨立診斷影片，不是原600局重播

使用相同source commit `e8b9756`、最終checkpoint、原100場景／RNG seed0和300個平行環境，在side 0做一次**不更新權重**的推論。
事先按原CSV的三種出界分組各選第一個不同scene，另選一個成功參考；不是隨機代表性抽樣。
採樣每50Hz保存球／機器人狀態及每步200Hz接觸計數，再以CPU的mjlab OffscreenRenderer轉影片；render不重跑物理。

| 場景／repeat | 原評測 | 此次診斷推論 |
|---|---|---|
| 0／0 | 球出界 | 3.10秒進球 |
| 1／0 | 球出界 | 3.82秒進球 |
| 6／1 | 球出界，未啟動我方踢球 | 8.46秒球出界，啟動我方踢球1次 |
| 2／0 | 進球 | 3.86秒進球 |

300局中有291局在終局、時間、最後觸球或出腳次數至少一項不同；其中65局終局種類不同。
根因尚未隔離，不能直接歸因硬體或宣稱只是正常浮點誤差。這次有額外記錄／同步／模型儲存等操作；相同seed不保證逐位重播。
**不把此次推論當新的正式分數，也不拿影片替代原600局的失敗原因統計。**

場景6／repeat1的此次診斷：5.42秒啟動我方踢球，最後我方接觸約5.58秒；球朝右側球門上緣附近前進後轉向，最後從+y側出界。
可觀察到出腳後仍可能出界；可能碰撞門框，但沒有球與門框的專用接觸紀錄，尚不能確定是哪個碰撞造成轉向。
球路圖 `diagnostic_ball_paths.png` 與影片均標明是獨立推論。
合併影片 `videos/duel_v3_seed1_diagnostics.mp4` 已完整解碼驗證，587幀、25fps、23.48秒，包含每段1秒終局停留。
