兩份逐局 CSV 按照 (scene_id, repeat, learner_side) 對齊，各有 600 個唯一鍵。475 局（79.2%）的終局相同。兩次都進球有 128 局，只有原始評測進球有 39 局，只有重測進球有 32 局。重測進球率低 1.17 個百分點，失球多 8 局。單次跨機器重測及同場景重複評測不足以估計一般性的跨機器變異，也未隔離逐局差異的成因。
