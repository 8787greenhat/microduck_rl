「出腳後有右腳接觸且進球」要求同局觸發踢球技能後有右腳感測器接觸，最後觀測觸球方為我方，且以進球結束。全部進球包含其他碰球方式，兩者分開報告。
準備位置案例球靜止、對手放遠；固定場景短測使用原題目前32組各2次。這些都不是新的正式600局結果，也不是多個 training seeds。

20項CPU測試通過；5批各64局有完整終局紀錄，actor/normalizer與官方技能未改、PPO更新0次。
修正的是高階控制器，不能說PPO自己已經學會停步或射門，也尚未證明整體對戰優於原v2。

程式與流程見 [說明文件](../../../docs/duel_stop_settle.md)。原v2的106/600及B/C資料均保留。

這次發布只有程式／結果整理，未重跑 GPU 評測或長訓練。隊友機器的可重現性仍待實際測試。
